# Cloud Security Journey ☁️

Hi! I'm a 3rd-year B.Tech CSE (Cybersecurity) student, currently learning about Cloud Security.

I've created this repository to keep track of everything I'm learning, from basic Linux commands to cloud security concepts and practical labs.

My main goal is to become a Cloud Security Engineer, preferably working with AWS. I know there is a lot to learn, so I'm starting with the basics and building my knowledge step by step.

## What I'm aiming for

My primary focus is **Cloud Security**.

Apart from that, I also want to learn:
